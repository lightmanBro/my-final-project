External API & Data Model Specifications

Attribute Data Type Source API UI Component Binding
id String (UUID) iTunes / Spotify DOM Data Attribute & URL Router
title / trackName String iTunes / Spotify Track Card & Audio Player Header

album / collectionName String iTunes / Spotify Track Metadata & Hero Spotlight
cover / artworkUrl String (URL 600px) iTunes / Spotify Album Artwork & Player Thumbnail
previewUrl String (AAC/MP3 Stream) Apple CDN / iTunes HTML5 Audio Engine & Visualizers
duration / durationMs String / Integer iTunes / Spotify Track Timeline & Scrubber
genre String iTunes / MusicBrainz Genre Filter Chips & Badges
lyricsPreview String (Text) Musixmatch API / Cache Artist Sidebar Lyrics Card
upcomingConcerts Array of Objects Concert / Tour Feed Artist Tour Dates List
